# Roadmap 3.2 — Odds Collector

Validated before starting 3.3: `python -m compileall -q v3 tests` and
`python -m pytest -q tests/v3`: **936 passed**. Offline network guard applies to
all V3 tests, including DNS. Issue #29 implemented; live acquisition remains gated.

Sources: [Issue 29](https://github.com/Chris34524/Match-Goals-AI-V3-Betting-Intelligence/issues/29),
[official V4 documentation](https://the-odds-api.com/liveapi/guides/v4/),
unchanged 3.1 contract/source matrix/audit. No historical requests.

Architecture: provider.py owns safe allowlists and explicit targets;
the_odds_api.py implements current V4 sport/event endpoints with fixed error codes,
timeouts and zero automatic retries; collector.py plans and parses observations;
reconciliation.py performs exact deterministic joins; quota.py guards reservations;
storage.py publishes immutable bundles; cli.py is independent of the operational core.

Supported mappings: h2h → 1X2 (home/draw/away); btts Yes/No → BTTS yes/no;
totals exact 1.5/2.5/3.5 → OVER_1_5/OVER_2_5/OVER_3_5, both over and under.
No missing prices, books or lines are filled. Unsupported markets remain absent.
Canonical source_published_at preserves provider last_update, separately from our UTC
capture clock. Invalid and post-kickoff records are rejected with reasons. Schema is
reused unchanged; fixture records carry review status and grant no ingestion rights.

Reconciliation policy reconciliation-1 requires a versioned sport→competition map,
exact normalized home/away (Unicode decomposition, casefold, punctuation removal,
whitespace collapse), kickoff within explicit default 300 seconds, and external ID
when known. Multiple candidates are AMBIGUOUS with no join. Live planning requires
external IDs; offline reconciliation can establish a candidate without one.

Quota defaults: hard 500/month, soft 450/month, max 30/run. Requested unique provider
markets × region equivalents × calls is a conservative upper bound. All totals
lines count once. Explicit bookmakers override regions: ceil(N/10) equivalents.
Event plans multiply by event count; featured endpoint requires event IDs.
Actual costs can be lower for missing markets or empty payloads. Provider headers
are preserved; reservations stay conservative even on timeout/crash. A locked,
append-only monthly ledger reserves the full plan before network. Failed calls are
not retried, and completed/failed run artifacts retain their audit. Cross-process
calls through this collector serialize against the same ledger. Separate output
roots/clients must not share a credential budget without an external coordinator.

Storage defaults to v3_data/odds; production path overrides must stay underneath it.
/tmp is permitted for isolated tests. Runs are SHA256(config + observed_at + source
SHA256), with raw responses, canonical JSONL and manifest. Atomic directory publication,
byte-identical repeat dedupe and conflict rejection prevent overwrites. Live per-event
raw artifacts retain each record's digest lineage. No operational data writes.

```sh
python -m v3.odds.cli plan --config tests/v3/fixtures/odds/config.json --targets tests/v3/fixtures/odds/targets.json
python -m v3.odds.cli collect-fixture --config tests/v3/fixtures/odds/config.json --targets tests/v3/fixtures/odds/targets.json --fixture tests/v3/fixtures/odds/response.json --observed-at 2026-11-01T17:00:00Z
python -m v3.odds.cli collect-live --config tests/v3/fixtures/odds/config.json --targets tests/v3/fixtures/odds/targets.json --live
```

Live requires flag, environment credentials and verified source-matrix project grant
covering requested markets. The matrix was not relaxed. No credentials requested,
printed or persisted. `live_status = blocked_missing_credentials` in this environment;
a credential alone would still leave acquisition blocked by source authorization.

Gaps/dependencies: real project grant, credentials and prospective provider coverage
validation remain external prerequisites. Live behavior was tested with injected
transports and synthetic authorization only; no API calls occurred. No Champion,
picks, staking or historical reconstruction were added.
