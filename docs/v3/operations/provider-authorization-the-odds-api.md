# The Odds API — project authorization attestation

Date reviewed: 2026-10-26
Project: Match Goals AI V3 — Betting Intelligence
Provider: The Odds API
Operational branch: `ops/prospective-evidence-cycle`
Related issue: #54

## Project access attestation

The project owner confirmed that a valid The Odds API key is configured locally through the `THE_ODDS_API_KEY` environment variable. The secret itself is not stored in Git, documentation, configuration JSON, logs, or ChatGPT.

This attestation records the existence of project access only. It does not record or disclose the API key.

## Terms review

The provider Terms and Conditions currently state that registered users may use service data for analytical dashboards, derived values, research, and statistical / machine-learning models. Raw-data-feed resale is prohibited. The terms reviewed were last updated 31 August 2026.

Evidence:

- https://the-odds-api.com/terms-and-conditions.html
- https://the-odds-api.com/
- https://the-odds-api.com/liveapi/guides/v4/
- GitHub Issue #54

## Authorized V3 scope

Allowed project use:

- official API only;
- current / upcoming odds only on the current free plan;
- target-driven acquisition;
- local retention for project analysis and model evaluation;
- derived probabilities, fair odds, edge, EV, calibration, CLV when temporally eligible;
- statistical / machine-learning evaluation;
- runtime storage under ignored `v3_data/` paths.

Not authorized by this attestation:

- raw feed resale or redistribution as a competing data service;
- credential publication;
- automatic sportsbook bet placement;
- Flashscore automation;
- paid historical endpoint use without a separate explicit project decision;
- treating the last observed pre-match price as an accredited closing price;
- retrospective backfill presented as prospectively captured evidence.

## Operational controls

- API key must remain in environment / secret storage only.
- `observed_at` must be generated by the V3 capture process and remain distinct from provider `last_update`.
- quota guards remain active (current default: 500 monthly hard / 450 soft / 30 max per run).
- no mass polling; use explicit targets and scheduler windows.
- a missed prospective snapshot remains `MISSED`; it is not reconstructed later.
- runtime artifacts must never be committed.

## Authorization conclusion

For the scoped uses above, The Odds API can be treated by V3 as a project-authorized official API provider once the source registry records this attestation. This authorization does not accredit opening or closing semantics and does not, by itself, make any captured observation OOS evidence; temporal eligibility remains independently validated.
