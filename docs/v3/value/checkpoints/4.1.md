# Checkpoint 4.1 — validated before 4.2

Issue #32. `compileall` successful; `python -m pytest -q tests/v3`: **1026 passed**.

Pure offline engine consumes unchanged Phase 3 canonical records inside envelopes
with explicit cutoff, period and rules. Model target includes match, market,
selection, line, model id/version, cutoff and evidence. Synthetic inputs require
`allow_synthetic=True`, model origin and each record's provider/origin equal to
`synthetic_test_only`. This never grants ingestion or production authorization.
Production uses the unchanged registry; currently no provider is authorized.

Math: finite non-boolean numeric p in [0,1]; fair odds 1/p, p=0 => null,
p=1 => 1. Decimal market prices must be finite and >1. Nonfinite arithmetic
blocks rather than serializing infinity. Complete 1X2 home/draw/away, BTTS
yes/no and totals 1.5/2.5/3.5 over/under are required, with no duplicates.
Same match/provider/bookmaker/market/line/clock/kickoff/snapshot semantics and
explicit period/rules/cutoff are required. No snapshot mixing.

q=1/odds; overround=sum(q)-1; proportional no-vig=q/sum(q), sum tolerance
1e-12 absolute. Absolute edge=p-no_vig; relative edge=p/no_vig-1, only for
positive denominator. EV=p*odds-1, retaining its sign. EV is unit return for
1X2/binary no-push markets; excludes commission, slippage and execution.

ELIGIBLE means valid mathematics and input eligibility, never a recommendation.
BLOCKED has null computed metrics and a structured exclusion code (invalid
probability/odds/contract, incomplete/mismatched set, temporal invalidity,
inactive price, closing, missing provenance, unauthorized source). Observed <=
cutoff < kickoff, observed < kickoff and explicit pre-match validity are required.
Only documented opening/current snapshots can be decision inputs.

Coverage: all five complete markets, missing/duplicate outcomes, bookmaker,
line and clock isolation, fair odds boundaries, NaN/inf/type rejection,
overround, no-vig, both edges, signed EV, closing, source isolation, inactive
prices, provenance, clocks and deterministic serialization; input immutability.

Gaps: no live authorization, probability calibration or historical threshold
validation. Finite float arithmetic is used without presentation rounding.
Phase 3 contracts/source code and operational core remain unchanged.
