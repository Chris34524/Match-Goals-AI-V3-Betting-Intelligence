## Null policy

Mínimo 3 muestras para tasas/medias según catálogo; H5/H10 son caps, no mínimos 5/10. Menos de 3 => null + insufficient_sample. Contador 0 sólo para sección válida vacía/ninguna muestra elegible; sección ausente/ambigua => null. partial_sample distingue ventanas incompletas.

## Leakage controls

Excluye todas las copias de duplicados, target, mismo día, futuro, fechas/IDs desconocidos, pair conflict, scopes no regulation/penales y scores inválidos. H2H permanece auxiliar, no entra a recent_form.

## Provenance

Por ventana ID/fecha/GF/GA/venue respecto a home actual/evidencia de score, source_artifact; manifest liga SHA-256 de history y salida; exclusiones completas. Fecha de muestra terminada es evidencia bajo política diaria V3; no inventa hora de publicación.

## Regresiones detectadas/corregidas

Test inicial escribía salida dentro del árbol protegido por nombre matches; se corrigió el fixture de test, sin relajar protección. Regresión de outputs anteriores: ninguna. La primera auditoría descubrió gramática H2H ordinaria de seis campos (49433 apariciones), sin sufijo G/E/P. Adaptador H2H específico reconoce igualdad exacta de esos seis campos, sin modificar adaptador 2.2 ni aceptar marcadores anotados. Salida candidata previa se reemplazó antes de continuar; hashes finales congelados abajo.

## Decisión final

Implemented como familia auxiliar, usar con sample_count y partial_sample; incorporación al entrenamiento requiere evaluación de valor incremental.
